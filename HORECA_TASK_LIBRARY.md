# HORECA_TASK_LIBRARY.md — Comprehensive Task Library (DRAFT v1)

Purpose: the master content source for the app's task library. Built to be exhaustive across full HoReCa (hotels, restaurants, cafes, QSR, bars, fine dining), not limited to the original checklist. This is a **content document for review**, not yet loaded into the app.

## How to read each task
Each task carries the fields the app needs:
- **Method**: how it's recorded — Tick / Data / Data+Tick / Tick+Photo / Data+Photo / Note / Note+Photo / Tick+Note / Multi
- **Freq**: how often
- **Pri**: Critical / High / Standard
- **Equip**: equipment type it attaches to (blank = general/area task)
- **Role**: who normally does it (Base / Mid / Top)
- **Limit**: a regulatory or best-practice threshold where one applies — **all figures marked (verify) must be confirmed against current UK FSA/legislation before deployment; they are starting points, not legal authority**
